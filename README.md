## Como ler cada questão

Toda questão contém os **4 campos obrigatórios**:

| Campo | Arquivo |
|-------|---------|
| Prompt (texto exato) | [`prompt.md`](Hill_Valley_Tech/Q1/prompt.md) por pasta Q{n} |
| Modelo + motivo da escolha | [`Entrega.md`](Hill_Valley_Tech/Q1/Entrega.md) |
| Output (resposta do modelo) | [`output.md`](Hill_Valley_Tech/Q1/output.md) |
| Justificativa (framework) | [`Entrega.md`](Hill_Valley_Tech/Q1/Entrega.md) |

Decisão de organização: [`Hill_Valley_Tech/ESTRUTURA.md`](Hill_Valley_Tech/ESTRUTURA.md).
